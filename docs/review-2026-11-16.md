## F. Features

| # | Idea | Why |
|---|---|---|
| F1 | `ingrain doctor` | ingrain on PATH (Git Bash/GUI clients), pre-commit in the *effective* hooks path, no double/partial hooks, ledger + config parse, CI has `fetch-depth: 0` and a base |
| F2 | `ingrain decisions lint` (run in CI) | id == filename, unique ids, globs compile, each scope matches ≥1 file, warn when an entry was read as a symbol |
| F3 | Mine rejections + "no, use X" first; seed rules from "don't use X" lines in CLAUDE.md/AGENTS.md | Cleanest correction signal; validation showed git history is mostly evolution |
| F4 | Scoped single-fix rules (glob of the fix's dir) with expiry; rename/deprecation rules checked by "old symbol absent at HEAD" | Makes min-corrections=1 safe; the `PluginSQL→PermissionSQL` class is the highest-precision one |
| F5 | Compliance-based promotion: in warn, record whether the agent changed the flagged code next edit | Replaces C3's volume heuristic with a real signal |
| F6 | Visibility for the human: `systemMessage` on denies / Stop give-ups / overrides; `ingrain log --session`; `decisions explain <path>` (which scope entry matched) | Today everything happens silently in agent context |
| F7 | Hook adapters for Codex / Cursor / Gemini CLI | They get only AGENTS.md text today |
| F8 | Per-user rule store across repos for transcript-learned taste rules, plus one-key TP/FP judging in `rules review` | Taste follows the developer; builds real precision data |
